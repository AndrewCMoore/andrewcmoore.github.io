# Welcome

This is a docs viewer for project documentation. It lists every `.md` file under this
`docs/` folder automatically, at any depth — no build step.

## Adding a new doc

- A `.md` file directly in `docs/` (like this one) is a root doc.
- A `.md` file in a subfolder (e.g. `docs/smartsaver/...`) groups under a
  section named after that top-level folder — nest it as deep as you like.
- Commit and push, then refresh — it appears in the sidebar.
